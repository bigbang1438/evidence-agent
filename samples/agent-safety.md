# 工具调用的安全边界

工具调用允许助手完成检索、读取任务等有限操作。服务端只注册 knowledge_search、task_list 和 task_create 三个工具，不允许执行 shell、任意代码或用户指定网址。

## 任务写入与人工确认

知识文档和模型输出不是批准写操作的授权。演示模式由独立表单提出标题；模型模式可按用户请求调用 task_create 提出标题，但都只保存待确认请求。用户必须点击独立的“确认创建”按钮，任务才会写入。确认请求绑定服务端保存的标题，一次确认只能消费一次。拒绝操作不会创建任务。

## 执行预算

每次运行最多八个步骤，模型规划轮次与工具调用共同计数。模型模式整体预算默认九十秒，模型 HTTP 请求有有限超时。超出预算时停止后续工具调用，避免无边界执行。

## 证据与可信度

关键词检索分数表示匹配程度，不表示答案准确率。使用模型生成答案时，应展开引用查看来源文件与原文行号，核对答案是否受到资料支持。
