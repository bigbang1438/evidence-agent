# BM25 与向量检索

BM25 是基于词项频率、文档频率和长度归一化的关键词排序算法。它适合精确术语、文件中的技术名词以及小规模本地文本检索。本项目采用英文词项和中文字符、二元词组，不使用语义向量。

向量检索将文本编码成数值向量，再通过相似度寻找语义相关内容。它通常需要嵌入模型和向量索引；关键词检索与向量检索的优缺点、成本和适用场景不同。

## 文档切分与引用

Markdown 和 TXT 导入后被切分为不超过六百字符的片段。每个片段保留原始文件名、起止行号与原文。长行也会切分，切分后的片段仍引用同一原始行。

## 演示模式和模型模式

演示模式只按固定规则检索片段并显示原文，不执行大模型推理。本地 Ollama 适配器使用 /api/chat 的非流式 tools 接口，由模型选择白名单工具，服务器校验与执行后返回 observation，再由模型继续规划或回答。默认不配置模型、不调用收费云端服务。

## 多轮与评测

SQLite 保存会话、已完成问答与工具轨迹；模型只接收当前会话最近六轮、合计不超过一万二千字符的历史。离线检索评测使用原创问题和黄金片段计算 Recall 与 MRR；可追溯覆盖率只验证文本与行号一致，不代表大模型答案正确率。
